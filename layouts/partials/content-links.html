Used by publication-item.html and project-card.html (the compact list/grid cards) and _default/single.html (the item's own page) so all three stay in sync automatically if a new link type is ever added here - add one `{{ with .Params.x }}` block below and it appears everywhere at once. Not every field applies to every content type (papers don't set `website`, projects don't set `doi`) - that's fine, each button is independently conditional on its own field being present, so a page with none of these set renders nothing at all. `blog_post` is authored as just the post's own slug under content/blog/ (e.g. blog_post: "hrm-part-2"), not a full URL like the other fields - it's resolved through .Site.GetPage so the link can never go stale if the post's permalink ever changes.
